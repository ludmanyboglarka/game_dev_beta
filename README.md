# Researcher Tycoon
## Interactive illustration of analytical variability in the field of social sciences

R analysis scripts, and the frequently updated version (including the JavaScript code for the web-based game) can be found at [this repository](https://github.com/natalijadokic/web-game-development). 

This repository contains the python script for the same analysis, purely for experimental reasons. 

The interactive game can be found at [this link](https://researchtycoonmeta.onrender.com), currently with only a beta version available.
